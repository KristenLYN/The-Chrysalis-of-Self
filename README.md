# The Chrysalis of Self

**The Chrysalis of Self** is a 2D side-scrolling puzzle game developed as a Software Engineering course project.  
The game explores the theme of **AI cognitive awakening** by transforming abstract concepts such as self-recognition, environmental cognition, trial-and-error learning, and cognitive growth into interactive game mechanics.

The project contains two core levels:

- **Level 1: Mirror Test** — focuses on self-recognition through mirror-based puzzle interaction.
- **Level 2: Spatial Memory Maze / Maze Trial & Error** — focuses on environmental cognition through movement, obstacle avoidance, mechanisms, and repeated trial-and-error.

## Project Overview

The game aims to combine educational value with puzzle-based gameplay.  
Instead of explaining AI cognition only through text, the project uses game mechanics to let players experience how an AI-like character gradually learns, explores, fails, adapts, and understands its environment.

Players interact with the environment through movement, jumping, climbing, buttons, elevators, traps, and other mechanisms. These interactions are designed to support the narrative theme of AI cognitive development.

## Level 2: Spatial Memory Maze

Level 2 focuses on environmental cognition.  
The player needs to explore a maze-like level, understand the relationship between different mechanisms, avoid hazards, and use environmental interactions to progress.

Main Level 2 mechanics include:

- Character movement and jumping
- Ladder climbing
- Moving obstacles and traps
- Button-triggered mechanisms
- Elevator movement
- Hazard avoidance
- Death and retry logic
- Level completion flow

This level is designed around the concept of **trial-and-error learning**, where players learn through repeated interaction, failure, and adjustment.

## How to Run

1. Clone this repository:

    git clone https://github.com/KristenLYN/The-Chrysalis-of-Self.git

2. Open the project with **Unity Hub**.

3. Select **Unity 2022.3 LTS** or a compatible Unity version.

4. Open the main scene in the Unity Editor.

5. Click **Play** to run the game.
